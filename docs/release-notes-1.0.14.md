# DriverCrate 1.0.14

Windows x64向けの変更です。公開は署名済みの配布物と新旧の索引入口の確認後に行います。

- 署名付きドライバー索引の有効期限と、索引内の候補ごとの有効期限を分けました。索引全体が有効な間は、期限内の候補を照合できます。期限が切れた候補は選択・取得・導入の手順から外れます。
- 取得・検査と導入の直前にも、選んだ候補の有効期限を確認します。配布物のハッシュ・署名・端末への適用性も確認します。
- ディスクリートGPUと内蔵GPUを同じ検索で確認できた場合は、内蔵GPUの候補を自動選択から外します。内蔵GPUの候補は手動で選べます。

実機でのドライバー導入は未確認です。新旧クライアントの配信仕様は [ADR 0607](adr/0607-independent-signed-index-record-expiry.md) に記載しています。
