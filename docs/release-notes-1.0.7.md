# DriverCrate 1.0.7

Windows x64向けの保守リリースです。

- 有効な推奨・初回候補の既定選択と、高DPIのチェック表示を調整しました。
- 導入後は処理済み対象を推奨表示から除外し、未選択・失敗・未処理と元route/leaseを保持します。全候補表示で結果を閲覧できます。
- 下部の正常検索表示を候補種別と件数へ短縮しました。部分取得元失敗と実診断保存不能/欠落は短く表示します。
- 診断11までのNeeds/AddReg/SYSTEM媒体処理・原取得枠と、診断12の処理後表示の変更を含みます。元hash/CAT/適用性/rank・同意・復旧の検証を維持します。
- 同じ診断wire v1の1.0.1〜1.0.7に限り元ログの全行形式を検証して追記し、header作成時版と実行中版を分けます。起動時の原prefixと通常容量rotationを区別し、不正/未知/リンクを採用しません（ADR0493）。

利用者は別PCの1.0.6診断11で選択7件のAPI成功を報告し、後続診断12の導入/更新/処理後表示も正常と確認しました。元ログの事後6有効/1unknown、Windows遅延登録注記、別PCの実行EXE rawhash未採取を保持します。これらは有限な旧byteの報告であり、1.0.7の実機導入成功・全device対応・Windows Server実機資格ではありません。

公開ソースからのビルド・試験、コード署名、ZIP/Setupの確認は[リリースチェックリスト](release-checklist.md)に従います。今回の確認範囲と未確認事項はリリース本文に記載します。
