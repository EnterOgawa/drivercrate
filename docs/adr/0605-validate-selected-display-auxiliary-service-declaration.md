# ADR 0605 選択したDisplay用の補助サービスとイベント登録を検査する

- 日付 2026-11-27
- 状態 構文・媒体と現用宣言を読み取る処理を実装。対応するドライバーの実機導入は未確認。

選択したDisplayのINFについて、通常の関連カーネルサービス一件と、必要な補助サービス一件の宣言を検証する。
補助サービスは同じ配布物の一意なDIRID 13の実行ファイルを参照し、付帯する登録は同じINFの一つのApplicationイベント源とする。
未知の開始アカウント、追加コマンド、依存、権限変更、他の登録先への作用は保留する。

現用の公開INFとDriver Store上の署名済み元INF、構成・保護・実行ファイル、イベント登録の値を読み取って照合する。
導入直前に選択機器、共用状況と保護された内容を再確認する。現用構成を検証できない場合は、新規作成として扱わず候補を保留する。
