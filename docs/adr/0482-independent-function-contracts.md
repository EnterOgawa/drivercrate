# ADR 0482: 宣言・定義それぞれの関数契約と参照省略の禁止

- 日付: 2026-11-11
- 状態: 採用。利用者の明示指示による824cの修正契約。
- 根拠: 最近のメソッドコメント確認に続く「整形済みでも参照だけの省略は禁止」「既存分も含め、すべて修正する」。

## 判断

宣言と定義の双方へ、それぞれ独立した概要、実際の引数名と方向、非voidの戻り値、必要な例外・所有・借用期間・thread・lock・失敗時状態を記載する。
基底/宣言の既存説明は、identity・overload・型・引数対応と実本体を照合して再利用できる。宣言と定義の説明は同じ実契約に保ち、実装側の具体条件やfakeの無作用を正確に説明する。
`@see`は補足参照として許可する。`@see`/`@copydoc`/`@inheritdoc`/`@copybrief`/`@copydetails`だけのblockや、概要を「参照先を見る」に置き換える省略を禁止する。
引数なしやvoidの空項目、手書きの関数名・呼出形式の署名複製は追加しない。名前付き型・field/enumの文書と関数契約を区別する。

関数・メソッドコメントの形式は承認済み見本の独立`/**`、行ごとの` *`、独立` */`と所属に応じたタブを使う。
定義/グローバル契約は規約8.5節の上下separatorを用いる。class内宣言/inlineは同じ正本18節のseparatorなしblock形式も許可し、適合済みのblockへseparatorを一律追加しない。
namespace定数は`//`、class field/定数・列挙値の前置`///`を維持する。

## 旧契約との関係

AGENTS13.4と採用規約8.4の「宣言正本・定義へ全文を複製しない」「copydoc可」はこの最新指示で更新する。
ADR0141の過去の判断・当時の移行実績は履歴として保持し、現在の契約は本ADRと更新した規約を使う。
旧案c_cpp_comment_standard.mdを再採用しない。

## 修正・検査

修正対象の元sourceと参照blockを原rawと対応表に固定し、不明な対応を一般的な作文で埋めず個別解決する。
sourceごとに契約を検査し、Doxygenが宣言/定義をmergeしたXMLだけで両側の記述を合格にしない。
既字句処理を使うcheckerへ関数・メソッドの形式・実引数/戻り値・参照省略を追加し、literal/型/field/条件コンパイル/overload等の境界を回帰確認する。
`source_method_contracts.py`を既標準gateへ結び、コメント無し関数と各raw blockを検査する。macro論理行は展開せず、即時lambdaのpostfixは同じinitializerとして扱う。
旧`audit_source_contracts.py`は宣言への集約と定義の参照置換を停止し、XMLの位置を使った双方の独立監査と、全件検証後だけの明示cleanupへ変更する。
字句解析はC++全構文や日本語の意味の完全判定ではない。未解析署名を黙って合格にせず、実body・所有・thread・失敗時状態との一致は個別reviewで確認する。
処理token/literal・署名/API・所有/権限・driver安全境界は変更しない。変更file版は一論理変更としてpatchを一回採番し、初回日・著作権・既履歴を保持する。
source/checker修正の確認であり、既署名配布物・cache・Releaseへの変更、runtime全試験、署名・新package・公開を行わない。
