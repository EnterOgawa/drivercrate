# ADR 0425: 導入後の全表示と通常行の選択入口

- 日付: 2026-11-02
- 状態: 採用。実装・内部検証はG13-I7r274b/c、主担当確認と配布物反映は274v。
- 関連: ADR 0416、0421、0422、0423、0424

有効な導入完了eventを状態機械が受理した後だけ、推奨・初回filterの内部状態とcheckboxを解除し、既存の全deviceを再構築する。個別結果と実際の事後観測を保持し、追加scanやOS再検出をしない。旧eventは画面を変えず、旧sessionの再選択は引き続き拒否する。全表示はfilter解除であり、全展開やscrollの変更を要求しない。

通常行の既定代表は、既存の推奨filter分類に該当する正当なUPDATE、INITIAL_INSTALL、または同scan/deviceの妥当な未導入観測に結合した取得前参照に限る。登録済み・未知の版不明参照、同版、旧版は自動代表とせずcheckboxを表示しない。詳細で一候補を明示指定すれば既存の選択意図を保持する。自動代表を明示指定としてfilter再構築や次scanへ持ち越さない。候補表示は導入許可ではなく、既存の同意、取得byte、署名、INF、適用性、復旧、事後観測の境界を維持する。画像から実導入成否を推測しない。

fake UIでfilter ONから成功・部分失敗の完了、全device・現在版・個別結果と旧event拒否を確認する。登録済み/未知・同版/旧版とCode28/更新・詳細指定、新scan時の旧自動代表失効を確認する。実App、通信、実導入は行わない。
