# DriverCrate 1.0.12

Windows x64向けのアプリ更新です。

- 対応する公式配布候補は、候補の詳細にある「検査用に取得」から、導入前に配布物の内容と利用規約を確認できます。導入には、検査後に対象を選び、規約と変更内容への同意が必要です。
- 対応するストレージドライバーでは、起動サービス、共有設定、追加で登録するINFなどを導入前に表示します。導入後は、反映を確認できた項目、再起動後に確認する項目、確認できなかった項目を表示します。
- 公開索引で示された対応Windowsのビルド範囲や機器別の条件を照合し、候補の取得前と導入前の判定に反映します。Windowsが返した機器IDは端末内で照合します。

署名と内容検査を通過した配布候補も、端末での適用性、導入への同意、復旧の準備を個別に確認します。実環境での導入および再起動後の起動確認は今回の検証範囲に含まれていません。
