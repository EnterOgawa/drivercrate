# 利用ガイド

DriverCrateはWindows x64向けの開発中プレビューです。現在の機器と候補を表示し、利用者が選んだ
driverだけを取得・検査・導入します。実行ファイルは管理者権限を要求します。Windows Update／WSUS、
proxy、証明書、UAC、組織のアプリ実行policyに従ってください。

## 現在の範囲

通常検索にはWindows Update、Windows Driver Store、公式配布元のProviderがあります。
配布情報だけの候補と、取得・内容検査・端末照合を経て導入可能になった候補は別です。
メーカー名や版が表示されたことだけでは取得・導入できるとは限りません。

署名索引からの共通取得、端末内照合、初回導入、標準INF導入と公式installer引継ぎはコードへ接続済みです。
共有package、同意、失効、部分失敗、復旧失敗等は決定的な人工試験で確認しています。
限定した実収集・取得と、INFを含むドライバー本体の内容検査には正常例があります。
通常画面で実端末に照合した正常候補の表示・実取得を一連で確認する受入は未完了です。
実driver導入と必要Extensionの個別反映は未確認です。

通常製品の固定公開鍵と独立したrevision1取得policyはsourceへ登録済みです。
ローカル索引受入・取得・署名tool等の開発optionは既定OFFで、過去の受入profileの鍵・同意・期限は引き継ぎません。
現行ソースに対応する収集用ローカルv5 packageは、このPCで配置・検査・保持／解除と非通信の
初期化・検証・停止export／import・人工中断からのnative再開を有限に確認済みです。空のローカルmonitorによる
確認で、実正本の結合・オンライン開始、実GitHub配布から通常画面までの正常例、日次継続と別PC移設は未受入です。
公開済みReleaseや全機器対応を意味しません。検証の区別は[テスト方針](testing.md)を参照してください。

## 起動前と配布物の確認

重要データをbackupし、Windowsと機器メーカーの復旧手順を確認してください。
Windows 10／11とWindows Serverのx64が設計対象ですが、全version・全機器の実測を完了していません。
実行ファイルは未署名です。SmartScreen、証明書警告、組織policyの拒否を回避しないでください。

正式な配布物を受け取った場合は同じ配布元のZIPと`.sha256`を比較します。次はファイル名の例で、
現在の公開assetの存在を示しません。

```powershell
Get-FileHash .\DriverCrate-0.1.0-windows-x64.zip -Algorithm SHA256
Get-Content .\DriverCrate-0.1.0-windows-x64.zip.sha256
```

不一致なら実行しないでください。SHA-256は破損・改変検知であり、制作者の認証ではありません。

## 検索と候補

1. `DriverCrate.exe`を起動してUACを確認し、「取得元」で今回使うProviderを確認します。
   設定変更は次の検索から有効になり、表示中の候補や導入先を変更しません。
2. 「更新を検索」を押します。検査用取得や回線の確認がある場合は、対象、規約、通信量と
   今回の許可範囲を確認します。検索開始はEULAや導入への同意ではありません。
3. 「種類→デバイス→候補」を矢印で開き、現在版、更新、同版、過去版、配布情報を区別します。
   不明な機器も一覧へ残り、名前・現在版の欠損だけでは未導入や更新なしと判定しません。
4. Provider別の無効、対象外、候補なし、候補あり、検索失敗、metadata拒否等と、対象・判定・候補件数を
   確認します。候補0件や未判定は「最新」「問題なし」の保証ではありません。

下部の全幅帯には確定した段階、処理済み件数、総件数、全体完了率を表示します。
同期APIから戻るまで進捗が変わらない場合があります。取消しは協調停止で、即時停止の保証はありません。
機器の問題コード28は「未導入」、登録属性取得時は「登録済み」、その他は「現在ドライバー未確認」です。
登録済みも正常動作や最新版を保証しません。

現在構成や候補の行でEnterまたはダブルクリックすると読取り専用詳細を開きます。
内容・署名・端末適合・必須条件・方式の未確認、拒否、未対応を確認してください。
詳細を開く操作は取得・導入への同意になりません。画面の機器情報を公開投稿しないでください。

WUA候補はWUAが現在の端末に適用可能と判定した未導入updateであり、世界で最も新しいOEM版の保証では
ありません。同じdevice・action・空でない明示versionが完全一致する取得元groupも同一内容の保証ではありません。

## 情報検索

「情報検索」は配布情報だけを確認する別modeです。初期選択は空で、今回の対応Providerと
制限・未知回線の許可を確認します。本体を取得せず、この一覧から導入できません。
「検索結果・条件」で予算、消費、列挙の完全性、停止理由を確認できます。適用性・導入準備は未測定です。
取得・導入には通常検索を新しく実行し、別途確認・同意してください。

## 選択と導入

導入可能な候補だけにcheckboxがあり、一deviceの基本driverにつき一計画を選びます。
現在版は表示専用です。推奨通常更新だけが初期選択の対象で、初回・同版・過去版を自動選択しません。
「推奨を全選択」「選択を全解除」の後も各対象と取得元を確認してください。
最終確認には件数、版、取得元、初回／旧版切替、必要INF・component、EULAと方式を表示します。
検査用取得の同意と実行同意は別です。必要条件が確認できない候補は実行できません。

clientでは最初に復元ポイントを開始します。開始失敗時はProviderを呼ばず中止し、開始後は成功・失敗・
例外でも終了通知します。ServerではSystem Restoreを呼びません。DriverCrateがbackupを作らないこと、
事前のsystem state／bare metal backupまたはhypervisor checkpointと復旧手順の確認を専用dialogに示し、
既定「いいえ」から管理者が明示同意した場合だけ進みます。

WUAはWUAの取得・導入を使います。Driver Storeと標準INFは直前に同じdevice、package、署名、依存閉包、
Windows選択条件を再確認し指定導入へ渡します。旧版切替には追加警告があります。
Driver Storeにあることも切替後の正常動作の保証ではありません。
公式installer方式は検証済みEXE／MSIの対話画面へ引き継ぎます。scan中に起動しません。
表示された選択driverの範囲を守り、追加appやfirmwareへ同意しないでください。
終了codeだけではdriver導入済みと確認できず、標準INFの内容合格やWindows rankとは別です。

## 結果と復旧

取得、導入API結果、実状態、再起動要否を別に確認します。一部失敗は個別結果へ残ります。
必要Extensionの個別反映が確認できなければ「適用未確認（Windows管理・個別反映は未確認）」を残します。
完了後は全Providerを自動検索せず、選択deviceの読取り専用事後確認と結果を保持します。
適用・変更なし・再起動待ち・実状態未確認を分け、現在版を推測で書き換えません。
scanは失効し、旧候補を再選択できません。次の導入には新しい検索が必要です。

問題時はDevice Manager、Windows Recovery Environment、メーカーの復旧手順を使用します。
clientの復元ポイントは完全backupではなく、Serverは事前に用意したbackup／checkpointを使います。
DriverCrateは復旧成功を保証しません。共有する診断にはversion、操作段階、一般化したHRESULTを使い、
機器ID、serial、title、URL、local pathを含めないでください。

収集専用ツールは[Collectorセットアップ](collector-setup-guide.md)、保護境界は
[セキュリティ設計](security.md)を参照してください。
