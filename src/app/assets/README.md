# DriverCrate application icon

`drivercrate-icon-master.png` は、DriverCrate専用の木箱application iconのmaster画像です。
`drivercrate.ico` は、Windowsでの表示に使用する16、20、24、32、40、48、64、128、256 pixelの
画像を収録しています。既存のicon setまたはSDIOのassetは転用していません。

## 制作情報

- 制作日: 2026-09-01
- 制作方法: OpenAI組み込み画像生成
- 用途: Windows desktop application icon
- 背景: 透過alpha

生成時は、かわいい表情を木製crateの正面へ組み込み、小サイズでも木箱の輪郭を判別できること、
文字や透かしを含めないことを指定しました。master画像からICOへの縮小にはLanczos resamplingを
使用しています。
